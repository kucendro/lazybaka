# bakasync

One-way sync from a public Bakaláři timetable into a dedicated Google Calendar.

- Reads the public timetable page. No Bakaláři account, no login.
- Writes to a calendar of its own. It never touches an event it did not create.
- One static binary. No database.

Four steps to a working sync: [Install](install.md), [Google](google.md),
[Configure](configure.md), [Run](run.md).
